# ugv-rcws-controller
Firmware for ESP32-based UGV Remote Controlled Weapon Station (RCWS) written in C. Features turret motor control, gun actuation, IMU-based 2-axis stabilization, and basic Fire Control System (FCS) functionality.

The project of the RCWS is being developed within the KNKM "Adamantium" student research group at AGH University of Science in Cracov.
